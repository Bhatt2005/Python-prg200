# Week 5 Assignment — Classes and Objects

**Course:** Introduction to Python Programming
**Topic:** Object-Oriented Programming — Classes, Objects, and Inheritance

---

## Overview

This repository contains solutions to the Week 5 assignment, which focuses on defining classes and creating objects in Python. Each program models a real-world scenario using OOP concepts such as constructors, instance methods, and inheritance.

---

## Programs

### Q1 — Bank Account Manager (`week5_q1_bank_account.py`)
Implements a `BankAccount` class for a cooperative bank in Lalitpur. Supports deposit, withdrawal, and balance inquiry. Withdrawal is rejected with a descriptive message if the amount exceeds the available balance.

### Q2 — Student Report Card (`week5_q2_student_report.py`)
Implements a `Student` class for a school in Bhaktapur. Automatically calculates each student's average marks, assigns a letter grade, and prints a pass/fail result based on the average.

### Q3 — Food Delivery App (`week5_q3_delivery_partner.py`)
Models a food delivery system with a parent class `DeliveryPartner` and three child classes — `BikeRider`, `Walker`, and `CarDriver` — each with their own earning formula. Demonstrates inheritance and method overriding. Prints each partner's earnings and identifies the top earner.

### Q4 — Bus Ticket Booking (`week5_q4_bus_booking.py`)
Implements a `Bus` class for Sajha Yatayat's Kathmandu–Pokhara route. Handles seat booking, detects duplicate bookings, tracks available seats, and prints the full passenger list.

---

## How to Run

```bash
python week5_q1_bank_account.py
python week5_q2_student_report.py
python week5_q3_delivery_partner.py
python week5_q4_bus_booking.py
```
